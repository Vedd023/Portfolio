## About

A personal portfolio designed around a dark cinematic, editorial aesthetic. Features asymmetrical layouts, editorial typography (Instrument Serif + Inter + JetBrains Mono), and a restrained design system focused on showcasing real projects.

**No frameworks. No bundlers. No `node_modules`.** A single `index.html` file with hand-written CSS and JavaScript.

---

## Sections

| Section           | Description                                                                 |
| ----------------- | --------------------------------------------------------------------------- |
| **Hero**          | Introduction, headline, CTAs, social links                                  |
| **Selected Work** | Featured project (Belt-Guard-AI) with editorial layout + project cards       |
| **About**         | Engineering approach and personal introduction                              |
| **Toolkit**       | Technologies grouped by category                                            |
| **Journey**       | Timeline of projects, hackathons, community work, education                 |
| **Contact**       | Email, GitHub, LinkedIn, Resume links + contact form                        |

Each project has a **case study detail view** with: problem statement, solution overview, architecture diagram, tech rationale, challenges, status, limitations, and lessons learned.
